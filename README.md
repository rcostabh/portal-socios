# Portal dos Sócios

App web (celular e computador) para os sócios das clínicas acompanharem resultados, repasses, comprovantes e documentos.

- Front-end estático (HTML/JS), publicado pelo GitHub Pages.
- Dados, login e arquivos no Supabase (projeto "Claude OP"), tabelas com prefixo `soc_` protegidas por RLS.
- `config.js` guarda a URL e a chave pública do Supabase.
